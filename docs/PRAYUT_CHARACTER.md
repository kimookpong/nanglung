# ประยุทธ์ จันทร์โอชา — ตัวละครล้อเลียนหนังตะลุง

> เอกสารรุ่นแรกด้านล่างเก็บประวัติการออกแบบ ปัจจุบันใช้ชื่อ **ไอยุทธ์** และเปลี่ยนเป็นชุดหนังดำฉลุ เนกไทแดง ดูแบบล่าสุดใน [SOUTHERN_CHARACTER_STYLE.md](SOUTHERN_CHARACTER_STYLE.md)

ออกแบบวันที่ 31 ตุลาคม 2026 สำหรับเชิดเป็นตัวละครที่สองคู่กับเท่ง

## แนวทางภาพ

- ผสมรูปหน้าล้อเลียนบุคคลกับตัวหนังแบน ขอบเข้ม รอยฉลุ และก้านเชิด
- ผมสั้นแสกข้าง หน้าผากกว้าง คิ้วเข้ม ตาค่อนข้างแคบ แก้มและคางเด่น ขยายศีรษะเพื่อให้อ่านใบหน้าได้บนเวที
- สูทสีน้ำเงินคราม เสื้อขาว และเนกไทฟ้า ตกแต่งปกและชายเสื้อด้วยเส้นทอง รอยฉลุ และเข็มกลัดรูปเรขาคณิตที่ออกแบบใหม่
- มือหนึ่งชี้ประกอบคำ อีกมือกางฝ่ามือ ท่าทดลองสลับพูด อธิบาย และพักฟัง เป็นจังหวะที่ออกแบบสำหรับการสาธิต

ตัวละครนี้เป็นงานล้อเลียนร่วมสมัยตามคำขอผู้ใช้ ไม่จัดเป็นตัวตลกดั้งเดิมในชุดงานวิจัยห้าตัวเดิม

## โครงเชิด

> แบบเวกเตอร์นี้เลิกใช้แล้วและลบไฟล์ออกจาก `src/` ปัจจุบันตัวละครนี้ใช้ PNG จากผู้ใช้ผ่าน `src/user-puppets.ts` ดู [USER_CHARACTER_ART.md](USER_CHARACTER_ART.md) ส่วนด้านล่างเก็บไว้เป็นบันทึกการออกแบบเดิม

`src/prayut-art.ts` เป็นข้อมูลเวกเตอร์ต้นทาง ใช้กับ `characterScene` ร่วมกันทั้ง Canvas และ SVG แขนมีข้อต่อไหล่–ศอก มือและข้อมือติดปลายแขน กรามล่างรวมริมฝีปากและรอยคางไว้ในชิ้นที่ขยับ ผม คิ้ว ตา และลายหูติดศีรษะ

ใช้หนึ่งมือห้านิ้วตามระบบเดิม: โป้งสั่งปาก ชี้/กลางสั่งแขน นางสั่งศีรษะ และก้อยสั่ง flip ทั้งตัว โปรไฟล์ปรับเทียบมือซ้าย/ขวาแยกจากรูปตัวละคร

เพิ่มเป็นรายการที่สองในคลัง โดยเก็บ ID ของตัวเดิมทั้งหมด ผู้ใช้ใหม่เริ่มคู่เท่ง–ประยุทธ์ ส่วนโปรไฟล์และตัวละครที่ผู้ใช้เดิมบันทึกไว้ยังใช้ต่อได้ เลือกประยุทธ์จากภาพในแผงตัวละครเพื่อเปลี่ยนเฉพาะมือที่ต้องการ
