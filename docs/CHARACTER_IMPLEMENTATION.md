# การสร้างชุดตัวละคร

วันที่ 31 ตุลาคม 2026

อัปเดตเท่งตามภาพอ้างอิงที่ผู้ใช้ส่ง: ศีรษะและจมูกใหญ่ ตาโตพร้อมขนตา ลายหู/ลำคอ สร้อยสีฟ้า ปากและปลายนิ้วแดง มือชี้/มือวง และผ้านุ่งตารางสีน้ำเงินพร้อมชายผ้าฟ้า เป็นเวกเตอร์แยกส่วนสำหรับเชิด ไม่ได้ใช้ภาพนิ่งทั้งตัวแทนโครงข้อต่อ

`src/theng-reference.ts` เก็บเส้นตามภาพและแปลงเข้าพิกัดโครงเชิดเดิม แขนมีรูปชิ้นส่วนเฉพาะและจุดหมุนไหล่/ศอกตามตำแหน่งในภาพ สีและเส้นตกแต่งใช้ร่วมกันทั้ง Canvas และ SVG ท่าพัก กรามและปลายนิ้วแดงติดชิ้นส่วนที่ขยับ ภาพ bitmap ที่ผู้ใช้แนบไม่ได้รวมในไฟล์เผยแพร่

## สิ่งที่เพิ่ม

- ชุดเวกเตอร์: เท่ง ประยุทธ์ ทักษิณ หนูนุ้ย สีแก้ว ยอดทอง ขวัญเมือง
- ทักษิณเป็นตัวเลือกที่สาม ดัดแปลงตามภาพตัวหนังที่ผู้ใช้แนบ มีสูทดำ เนกไทแดง ผ้าคาดเอวแดงทอง และหมุดแขนที่เคลื่อนตามจุดหมุน ดู [THAKSIN_CHARACTER.md](THAKSIN_CHARACTER.md)
- ประยุทธ์เป็นตัวละครล้อเลียนร่วมสมัย เพิ่มเป็นตัวเลือกที่สองสำหรับจับคู่กับเท่ง มีสูทคราม เนกไทฟ้า รอยฉลุขอบทอง และชิ้นส่วนขยับตามโครงเชิดเดิม ดูรายละเอียดใน [PRAYUT_CHARACTER.md](PRAYUT_CHARACTER.md)
- รูปศีรษะ ผม ลำตัว ผ้านุ่ง มือ และสัดส่วนต่างกัน ไม่ใช้หุ่นสวมชฎารูปเดียวเปลี่ยนสี
- แขนมีจุดหมุนไหล่และศอก มือแต่ละข้างติดปลายแขน กรามล่างติดศีรษะ เคราของหนูนุ้ยติดกราม
- เท่งมีมือวงซ้าย/มือชี้ขวา สีแก้วมีมือกำ และแต่ละตัวมีท่าพักต่างกัน
- มีดเหน็บของเท่ง ตะไกรหนีบหมากของหนูนุ้ย และกริชของยอดทองเปิด/ปิดได้ อุปกรณ์ติดกับเอวหรือมือ จึงเคลื่อนตามชิ้นส่วนที่ถือ
- ปากและศีรษะมีมุมจำกัดเฉพาะตัว ข้อศอกทำงานสัมพันธ์กับไหล่โดยใช้นิ้วเดิม ไม่มีการเพิ่มจำนวนอินพุต
- คลังตัวละครในสตูดิโอ รายละเอียด/ที่มา และไฟล์ SVG ท่าพักสำหรับดาวน์โหลด
- สลับตัวแล้วคงตำแหน่ง การปรับเทียบ มือที่เลือก หน้าที่นิ้ว และทิศทางเดิม ใช้การผสานภาพช่วงสั้น และให้ gesture หันต้องปล่อยใหม่ก่อนสั่ง
- ท่าตัวอย่างแยกบุคลิก ใช้เฉพาะโหมดทดลอง ไม่เคลื่อนตัวละครอัตโนมัติทับมือผู้แสดงในโหมดกล้อง

## ไฟล์

- `src/characters.ts`: แหล่งข้อมูลเวกเตอร์และโครงข้อต่อร่วมสำหรับ Canvas/SVG
- `src/performance.ts`: ลำดับท่าตัวอย่างรายตัว
- `scripts/build-character-assets.mjs`: สร้าง SVG ห้าตัวและภาพรวม
- `public/characters/*.svg`: ไฟล์เวกเตอร์ท่าพัก แก้ไขต่อได้
- `docs/characters-sheet.svg`: ภาพรวมเปรียบเทียบสัดส่วนและท่าพัก
- `tests/characters.html`: ภาพตรวจสามระดับการขยับและกลับทิศ

SVG ท่าพักรวมอุปกรณ์ประจำตัวตามค่าเริ่มต้น ไม่ใช่ภาพ export ตามท่าปัจจุบันบนเวที ถ้าแก้ไฟล์ SVG ที่สร้างไว้โดยตรง ต้องนำการแก้กลับไปที่ `characters.ts` ก่อน export รอบถัดไป มิฉะนั้นตัวสร้างไฟล์จะเขียนทับ

## ขอบเขต
