# ทักษิณ ชินวัตร — ตัวละครล้อเลียนหนังตะลุง

> เอกสารรุ่นแรกด้านล่างเก็บประวัติการออกแบบ ปัจจุบันใช้ชื่อ **แม้ว** และเปลี่ยนจากผ้าคาดเอวแดงทองเป็นสูทหนังดำฉลุตามภาพแนบชุดใหม่ ดูแบบล่าสุดใน [SOUTHERN_CHARACTER_STYLE.md](SOUTHERN_CHARACTER_STYLE.md)

ออกแบบวันที่ 31 ตุลาคม 2026 เป็นตัวเลือกที่สามต่อจากเท่งและประยุทธ์ โดยยึดภาพตัวหนังที่ผู้ใช้แนบเป็นแบบหลัก

## รายละเอียดตามภาพ

- ผมแสกข้างปัดเป็นคลื่น ศีรษะใหญ่ คิ้วโค้ง ตาหยียิ้ม รอยแก้ม และปากสีแดง
- สูทดำ เสื้อขาว เนกไทแดง เข็มธงไทย และขอบปกเส้นสีงาช้าง
- ผ้าคาดเอวแดงลายทอง มีปม ชายผ้าสองข้าง ลายข้าวหลามตัด และพู่
- ท่าพักยกฝ่ามือข้างหนึ่ง อีกข้างผายลง มีหมุดไหล่ ศอก ข้อมือ เข่า และรายละเอียดรองเท้าตามภาพ

งานที่ใช้ในแอปเป็นเวกเตอร์ดัดแปลงจากภาพ ไม่ได้ใช้ bitmap ทั้งตัว ตัวละครใช้พิกัดหันขวาตามโครงเชิดร่วม และกลับซ้าย/ขวาได้ด้วยคำสั่ง flip

## โครงสร้างสำหรับเชิด

> แบบเวกเตอร์นี้เลิกใช้แล้วและลบไฟล์ออกจาก `src/` ปัจจุบันตัวละครนี้ใช้ PNG จากผู้ใช้ผ่าน `src/user-puppets.ts` ดู [USER_CHARACTER_ART.md](USER_CHARACTER_ART.md) ส่วนด้านล่างเก็บไว้เป็นบันทึกการออกแบบเดิม

`src/thaksin-art.ts` เก็บเส้นและสี แปลงพิกัดจากภาพอ้างอิงเข้าสู่โครงเชิดเดิม ข้อต่อไหล่–ศอกแบ่งแขนเป็นสองชิ้น มือและหมุดข้อมือติดปลายแขน กรามล่างรวมริมฝีปากล่าง ส่วนทรงผม หู คิ้ว และตาติดศีรษะ ลายผ้าคาดเอวติดลำตัว ขาโค้งตามภาพเป็นท่าคงที่และเคลื่อนตามลำตัว

เพิ่มรายละเอียดบนชิ้นแขนสำหรับหมุดไหล่และศอกโดยยังใช้จุดหมุนเดียวกับระบบเดิม ใช้เส้นเวกเตอร์ชุดเดียวกันทั้ง Canvas และ SVG ท่าพัก

หนึ่งมือยังควบคุมหนึ่งตัวละครด้วยห้านิ้ว เลือกทักษิณให้มือซ้ายหรือขวาเพื่อเชิดคู่กับตัวอื่นได้ โหมดสองมือยังแสดงพร้อมกันสองตัว การเพิ่มตัวเลือกนี้ไม่เปลี่ยนโปรไฟล์ปรับเทียบหรือคู่ตัวละครที่บันทึกไว้

## แหล่งแบบและการตรวจ

ภาพอ้างอิงเป็นภาพที่ผู้ใช้ส่งพร้อมคำขอ “คนที่ 3 คือ ทักษิณ ชินวัตร” ภาพต้นทางไม่ได้รวมใน repository หรือไฟล์เว็บไซต์ ผลที่ส่งเป็นเวกเตอร์ดัดแปลงสำหรับระบบดิจิทัลและยังไม่ได้ตรวจทานโดยครูหนัง

ตรวจท่า 0%, 50% กลับด้าน และ 100% ของทุกตัว รวมแขน กราม หมุดข้อต่อ และผ้าคาดเอว ตรวจคู่เท่ง–ทักษิณบน Canvas และการกู้คืนคู่หลัง reload แล้ว ปุ่มเลือกเจ็ดตัวกับกล่องข้อมูลพอดีจอขนาดที่บันทึกไว้ใน [VERIFICATION.md](VERIFICATION.md)
