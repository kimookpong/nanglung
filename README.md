# NangLung Studio

สตูดิโอหนังตะลุงดิจิทัลแบบ 2 มิติ ใช้ **หนึ่งมือ ห้านิ้ว ต่อหนึ่งตัวละคร** เลือกเชิดหนึ่งมือหนึ่งตัว หรือสองมือสองตัวพร้อมกันได้

เปิดใช้งาน: **[kimookpong.github.io/nanglung](https://kimookpong.github.io/nanglung/)** · [GitHub repository](https://github.com/kimookpong/nanglung)

## หน้าสตูดิโอใหม่

เวทีขนาดใหญ่คู่กับแผงตัวละคร/กล้อง โทนถ่าน–ครีม–สีชาด รายการแสดงครบทุกแบบทันที แถบนิ้วปิดเป็นค่าเริ่มต้นและกดเปิดได้ หน้าจอหลักไม่มี scrollbar ทั้งคอมและมือถือ ดู [การวิเคราะห์และออกแบบ UX/UI](docs/UX_REDESIGN.md)

ช่องเช็ก **ซ้าย / ขวา** ใต้เวทีแสดงชื่อตัวละครของแต่ละมือ เช็กหนึ่งข้างเพื่อเชิดหนึ่งตัว เช็กสองข้างเพื่อเชิดพร้อมกันสองตัว เอาเครื่องหมายออกเพื่อพักตัวนั้น และเอาออกทั้งสองข้างเพื่อพักทั้งหมด สถานะตรงกับเมนูหนึ่งมือ/สองมือและปุ่มพัก

## ตัวละครหลักหกตัวและคลังตัวหนัง

รายการด้านข้างแสดงครบทั้ง 10 แบบทันที: **เท่ง ไอยุทธ์ แม้ว วิตร หนู เอก หนูนุ้ย สีแก้ว ยอดทอง และขวัญเมือง** เลือก checkbox ซ้าย/ขวาบนการ์ดเพื่อแสดงตัวนั้น หรือคลิกภาพเพื่อเลือกเชิดได้โดยตรง การปรับเทียบมือและหน้าที่นิ้วยังคงเดิม ดู [แนวทางออกแบบชุดหนังตะลุงร่วมสมัย](docs/SOUTHERN_CHARACTER_STYLE.md)

- เท่ง: ปรับตามภาพผู้ใช้ ตาโต จมูกใหญ่ สร้อยฟ้า มือชี้ปลายแดง มือวง และผ้านุ่งตารางสีน้ำเงิน พร้อมมีดเหน็บ
- ไอยุทธ์ — ประยุทธ์ จันทร์โอชา: PNG ใหม่จากผู้ใช้ เครื่องแบบดำ ขอบทอง อินทรธนู แถบสี และเข็มขัด
- แม้ว — ทักษิณ ชินวัตร: PNG ใหม่จากผู้ใช้ สูทดำ เนกไทแดง และผ้านุ่งลายแดงทองเขียว
- วิตร — ประวิตร วงษ์สุวรรณ: PNG ใหม่จากผู้ใช้ รูปร่างป้อม แก้มเต็ม เครื่องแบบดำ ขอบทอง
- หนู — อนุทิน ชาญวีรกูล: PNG ใหม่จากผู้ใช้ ชุดคราม ผ้าคาดธงไทย ตราหน้าอก และนาฬิกา
- เอก — ธนาธร จึงรุ่งเรืองกิจ: PNG จากผู้ใช้ เสื้อโปโลสีส้ม ผมตั้ง นาฬิกา และรองเท้าผ้าใบ ตัดพื้นขาวด้วยหน้ากากแสดงผล
- หนูนุ้ย: เตี้ย คอตก พุงยื่น มีเครา พร้อมตะไกรหนีบหมาก
- สีแก้ว: ศีรษะล้าน บ่าแน่น มือหนักแน่น
- ยอดทอง: ผมหยิก พุงเด่น พร้อมกริช
- ขวัญเมือง: หน้าผากสูง จมูกยาว และท่ากล่าวนำ

อุปกรณ์ประจำตัวของเท่ง หนูนุ้ย และยอดทอง เปิด/ปิดได้ที่ **ตั้งค่า → เวที** ปุ่ม ? ใต้เวทีมีข้อมูล แหล่งอ้างอิง และลิงก์ดาวน์โหลด SVG ท่าพักสำหรับนำไปแก้ไขต่อ

เท่งใช้เวกเตอร์ตามภาพเดิม ส่วน **ไอยุทธ์ แม้ว วิตร หนู เอก ใช้ PNG ที่ผู้ใช้ส่งโดยตรง** และแยกชิ้นสำหรับเชิด ตัวหนังในเมนูอื่นวาดจากการศึกษาเอกสารและภาพอ้างอิง ดู [แบบล่าสุดและวิธีแยกชิ้น](docs/USER_CHARACTER_ART.md) และ [งานศึกษาตัวหนังดั้งเดิม](docs/CHARACTER_RESEARCH.md)

ภาพรวมตัวละครหลักทั้งหกอยู่ใน [docs/characters-sheet.svg](docs/characters-sheet.svg) และไฟล์แยกทั้งสิบตัวอยู่ใน `public/characters/`

## จัดตัวละครหลายตัวบนเวที

เลือกมือจากชื่อใต้เวที แล้ว **คลิกตัวละครบนเวทีหรือการ์ดในรายการเพื่อสลับควบคุม** การ์ดมีครบทุกแบบโดยไม่ต้องกดเพิ่ม ตัวที่ยังไม่แสดงจะปรากฏและพร้อมเชิดเมื่อคลิกภาพ อีกมือยังควบคุมตัวของตนในโหมดสองมือได้ เลือก checkbox ซ้าย/ขวาเพื่อแสดงหรือย้ายฝั่ง เอาเครื่องหมายออกเพื่อซ่อนตัวนั้น รายการ ท่า และตัวซ้ำที่เคยบันทึกไว้ยังเก็บในเบราว์เซอร์

บนการ์ดแต่ละตัวมี checkbox **ซ้าย / ขวา** สำหรับฝั่งที่แสดงบนเวที เลือกหนึ่งฝั่งเพื่อแสดงหรือย้าย เอาเครื่องหมายออกเพื่อซ่อน การย้ายฝั่งไม่เปลี่ยนมือที่ใช้เชิด ส่วนใต้เวทีกดชื่อมือเพื่อเลือกมือ และใช้ checkbox เปิด/พักการควบคุมแต่ละมือ

ฉากใช้โทนผ้าแสงอุ่น ตัวละครแต่ละตัวหัวคมชัดแล้วค่อย ๆ เบลอและขยายเล็กน้อยลงถึงขา โลโก้ด้านบนเป็น PNG โปร่งใส ดู [คู่มือฉากและการจัดตัวละคร](docs/SCENE_AND_CAST.md)

## เปิดใช้งาน

ต้องมี Node.js **22.22 ขึ้นไป** หรือ Node.js รุ่น LTS ที่รองรับ Vite 8 และเว็บแคม ใช้ Chrome/Edge รุ่นปัจจุบันเป็นเบราว์เซอร์สำหรับทดสอบการแสดงก่อน

บน Mac ดับเบิลคลิก `เปิดสตูดิโอ.command` เพื่อเปิด Terminal และสตูดิโอในเบราว์เซอร์ หรือใช้:

```sh
cd /Users/cdimac/myProject/NangLung
npm ci
npm run dev -- --open
```

เปิด URL ที่ Vite แสดงใน Terminal ปกติคือ **http://127.0.0.1:5173/** หากพอร์ตถูกใช้ Vite จะเลือกพอร์ตถัดไป หยุดด้วย `Ctrl+C`

ครั้งแรกต้องมีอินเทอร์เน็ตเพื่อติดตั้งแพ็กเกจและเตรียมโมเดล หลังเตรียมแล้วระบบตรวจจับจะอ่านโมเดลและ WASM จากเครื่อง ไม่มีการส่งภาพกล้องไปเซิร์ฟเวอร์ ไม่มีบริการภายนอกที่ต้องใส่ API key

หากต้องการใช้ build สำหรับทดลองแสดง:

```sh
npm run build
npm run preview -- --open
```

ไฟล์พร้อมให้บริการเว็บอยู่ใน `dist/` ให้เปิดผ่าน HTTP บน localhost หรือ HTTPS ไม่ใช่ดับเบิลคลิก `index.html` โดยตรง ค่า build ปกติใช้ที่รากเว็บไซต์ สำหรับ GitHub Pages มี workflow ที่อ่าน base path และ deploy อัตโนมัติไว้แล้ว ดู [วิธีเผยแพร่บน GitHub Pages](docs/GITHUB_PAGES.md)

## วิธีเชิด

1. กดชื่อมือซ้าย/ขวาใต้เวที แล้วคลิกภาพตัวละครในรายการ หรือเลือกฝั่งแสดงจาก checkbox บนการ์ด
2. เลือกมือซ้าย/ขวาตามมือจริง แล้วกด **เปิดกล้องเพื่อเชิด** และอนุญาตกล้องในเบราว์เซอร์
3. หันฝ่ามือเข้ากล้อง ให้เห็นนิ้วครบ และจัดแสงบริเวณมือให้สม่ำเสมอ
4. กด **ปรับเทียบมือ** แล้วเก็บสี่ท่า: กางมือ → งอนิ้ว/หุบโป้ง → มุมซ้ายบน → มุมขวาล่างของพื้นที่ขยับมือ
5. เลือก **เต็มจอ** สำหรับแสดงเฉพาะเวที ใช้ Esc ออกจากเวที

### โหมดสองมือ สองตัวละคร

เช็กทั้ง **ซ้าย / ขวา** ใต้เวที หรือเลือก **2 มือ** ในแผงข้าง แล้วเปิดกล้อง ระบบจับคู่มือซ้ายและมือขวากับตัวละครคนละตัว โดยใช้ handedness ร่วมกับตำแหน่งมือ ไม่อ้างอิงลำดับผลตรวจจับ

กดชื่อมือ **ซ้าย / ขวาใต้เวที** แล้วคลิกตัวละครบนเวทีหรือการ์ดในรายการเพื่อกำหนดตัวหนังให้มือนั้น ปรับเทียบมือทีละข้าง โปรไฟล์ซ้ายและขวาแยกกัน แผงสัญญาณนิ้วแสดงค่าจากกล้องของมือที่เลือก การเลือกมือในโหมดสองมือไม่หยุดอีกตัว ผู้ใช้ใหม่เริ่มคู่เท่ง–ประยุทธ์ ส่วนตัวละครและโปรไฟล์ที่เคยบันทึกไว้จะไม่ถูกเขียนทับ

แต่ละมือขยับปาก แขน ศีรษะ ตำแหน่ง และใช้นิ้วก้อย flip ได้อิสระ มือหนึ่งหลุดจากภาพจะพักเฉพาะตัวของมือนั้น ในภาพกล้องมีจุดมือคนละสีพร้อมป้าย L/R และแถบสถานะแสดงจำนวนมือที่พบ หน้าที่นิ้ว ความไว ความนุ่มนวล และสีเวทีเป็นค่าร่วมทั้งสองมือ ปุ่มพัก/รีเซ็ตควบคุมทั้งเวที

ระบบใช้การเชิดผ่านกล้องเพียงอย่างเดียว ตัวละครคงท่าไว้เมื่อกล้องปิด จำนวนมือและตัวละครของแต่ละมือบันทึกในเครื่อง การตั้งค่าและการปรับเทียบรุ่นเดิมยังใช้ต่อได้

| ส่วนควบคุม | หน้าที่เริ่มต้น |
| --- | --- |
| เลื่อนฝ่ามือ | เลื่อนตัวหนังซ้าย–ขวา / ขึ้น–ลง |
| เอียงแนวฝ่ามือในภาพ | เอียงลำตัว |
| โป้งกาง–หุบ | เปิด–ปิดปาก |
| ชี้งอ–เหยียด | ยก–ลดแขนขวาของตัวละคร |
| กลางงอ–เหยียด | ยก–ลดแขนซ้ายของตัวละคร |
| นางงอ–เหยียด | ก้ม–กลับศีรษะตั้งตรง |
| ก้อยงอค้าง | สลับหันซ้าย/ขวาหนึ่งครั้ง |

การหันตัวใช้สัญญาณนิ้วก้อยตั้งแต่ **60%** ปล่อยนิ้วประมาณ 0.2 วินาทีก่อนพร้อมสั่ง แล้วงอค้างประมาณ 0.35 วินาที ตัวหนังจะหมุนผ่านสันแล้วเปิดออกอีกด้านภายในประมาณ 0.52 วินาที ต้องปล่อยก่อนสั่งซ้ำ และหลังมือหลุดต้องปล่อยเพื่อพร้อมสั่งใหม่ด้วย การพักจะหยุด motion กลางท่าได้

ปรับความไวและหน้าที่ได้ใน **ตั้งค่า → นิ้ว** การเลือกหน้าที่ที่นิ้วอื่นใช้อยู่จะสลับสองนิ้วให้โดยอัตโนมัติ จึงคงหนึ่งนิ้วต่อหนึ่งหน้าที่เสมอ โปรไฟล์ปรับเทียบเก็บแยกมือซ้าย/ขวาในเบราว์เซอร์ของเครื่องนี้

ความนุ่มนวลมากขึ้นช่วยลดการสั่นแต่เพิ่มความหน่วง ทดสอบหาค่าที่เหมาะกับผู้แสดงและเครื่องจริง

## การจัดหน้าจอ

หน้าสตูดิโอยึดพื้นที่จอโดยไม่มีแถบเลื่อนแนวตั้งหรือแนวนอน เวทีใช้พื้นที่หลัก ส่วนตัวละคร กล้อง และปุ่มที่ใช้เชิดอยู่ด้านข้าง บนจอแนวตั้งจะย้ายแผงควบคุมลงด้านล่าง โดยคงสัดส่วนภาพเวที

หน้าหลักเหลือเฉพาะส่วนที่ใช้เชิด ตัดเมนูนำทาง ข้อความซ้ำ และตัวเลขวิเคราะห์ออก การตั้งค่าเปิดเป็นกล่องสามแท็บ: **มือ / นิ้ว / เวที** รองรับปุ่มลูกศรเพื่อสลับแท็บ ข้อมูลตัวละครและคู่มือเปิดเฉพาะเมื่อต้องการ

ตรวจขนาดจอ 320×480, 320×568, 375×812, 568×320, 844×390, 1280×720 และ 1366×768 รวมกล่องตั้งค่าบนจอเล็ก โดยไม่มีปุ่มหลักล้นจอ

## ปุ่มลัด

| ปุ่ม | การทำงาน |
| --- | --- |
| Space | พัก / เชิดต่อ |
| R | รีเซ็ตท่าตัวละครและตำแหน่งอ้างอิง |
| F | เวทีเต็มจอ |
| Esc | ออกจากเวทีเต็มจอ / ปิดกล่องโต้ตอบ |

ปุ่มลัดจะไม่แทรกขณะกำลังปรับแถบเลื่อน เลือกค่า หรือเปิดกล่องโต้ตอบ

## สิ่งที่ทำไว้

- ตัวหนังวาดด้วย Canvas แยกลำตัว แขนสองข้าง ศีรษะ และกรามล่าง พร้อมลายฉลุและก้านเชิด
- ตำแหน่ง/แนวฝ่ามือแยกจากค่าของนิ้วทั้งห้า คำนวณการงอจากข้อต่อ 3 มิติ
- MediaPipe ทำงานใน **classic Web Worker** เพื่อรองรับ WASM loader ที่ใช้ `importScripts`
- ใช้ GPU เมื่อ OffscreenCanvas/WebGL2 และโมเดลรองรับ พร้อม CPU สำรอง
- ส่งภาพครั้งละหนึ่งเฟรม ไม่สะสมคิว และปฏิเสธผลที่เก่ากว่า 350 ms
- มือหลุดช่วงสั้นจะค้างท่า หลังจากนั้นแขน ปาก และศีรษะค่อย ๆ กลับท่าพัก โดยคงตำแหน่งตัวไว้
- เมื่อกลับเข้าภาพจะตั้งฐานตำแหน่งใหม่จากท่าปัจจุบัน เพื่อลดการกระโดด กด R เพื่อกลับการจับคู่ตำแหน่งแบบตรง
- เลือกมือและกล้อง ภาพกระจก เปิด/ปิดจุดมือ ปรับสีเวที และบันทึกค่าในเครื่อง
- จัดการกรณีปฏิเสธสิทธิ์ กล้องหาย โมเดลโหลดไม่ได้ และยกเลิกการเปิดกล้องระหว่างรอ

ทดสอบตรรกะการปรับเทียบ มุมข้าม ±180 องศา การสลับทิศ การกลับเข้าภาพ ผลลัพธ์เก่า การเก็บค่า และ lifecycle กล้อง/การข้ามเฟรมด้วย Vitest

ขณะเปิด dev server สามารถตรวจระบบจริงเพิ่มได้:

- `/tests/vision.html` รัน worker + WASM + โมเดลจริงกับภาพตัวอย่างจาก MediaPipe ตรวจมือทั้งสองข้างและจุดข้างละ 21 จุด โดยไม่เปิดกล้อง
- `/tests/frame-timing.html` เปรียบเทียบความเร็วรอบวาดภาพว่างกับตัว renderer เพื่อแยกข้อจำกัดของเบราว์เซอร์พรีวิวจากเวลาวาดตัวละคร
- `/tests/layout.html?width=1366&height=768` ตรวจขนาดหน้าจอจริงภายใน iframe โดยปรับสเกลเฉพาะกรอบพรีวิวให้พอดีกับหน้าทดสอบ
- `/tests/layout.html?width=320&height=480&dialog=calibration` ตรวจกล่องปรับเทียบพร้อมข้อความผิดพลาด เป็น fixture เฉพาะหน้าตา ไม่ได้ทดสอบกล้อง
- `/tests/characters.html` แสดงตัวละครทุกตัวที่ค่า 0%, 50%, 100% รวมภาพกลับทิศ สำหรับตรวจปาก ไหล่ ศอก และอุปกรณ์

หน้าทดสอบและภาพ fixture ไม่รวมใน `dist/` ดูแหล่งที่มาของภาพใน `tests/fixtures/README.md`

ผลตรวจและขอบเขตที่ยังไม่ได้ทดสอบอยู่ใน [docs/VERIFICATION.md](docs/VERIFICATION.md)

## ขอบเขตและข้อจำกัด

นี่คือต้นแบบที่พัฒนาฟังก์ชันครบตามขอบเขตหนึ่งมือห้านิ้ว ยังต้องปรับเทียบและทดลองกับผู้เชิด/เว็บแคมจริงก่อนใช้แสดง การทดสอบจากภาพยืนยันการโหลดและตรวจจับของโมเดล แต่ไม่ยืนยันความคล่องในการเชิดหรือความแม่นยำของทุกนิ้วในทุกท่า

เป้าหมาย 30 FPS และความหน่วงใน PLAN.md เป็นเกณฑ์สำหรับวัดบนเครื่องเป้าหมาย ยังไม่ถือว่าผ่านจากการ build หรือจากเวลารันโมเดลเพียงอย่างเดียว เวลา inference ไม่ใช่ความหน่วงรวมจากมือถึงจอ

นิ้วบังกัน หันมือด้านข้าง หรือขยับนิ้วนาง/ก้อยร่วมกันอาจทำให้คำสั่งคลาดเคลื่อน ควรทดสอบการสลับหน้าที่และปรับความไวให้เหมาะกับผู้เชิด ระบบเลือกมือซ้าย/ขวาและความต่อเนื่องของตำแหน่ง ไม่ใช่ระบบยืนยันตัวบุคคล

แต่ละแขนแยกต้นแขนกับปลายแขน โดยหนึ่งนิ้วขับชุดท่าไหล่–ศอกที่กำหนดไว้ ยังไม่ใช่การสั่งสองข้ออิสระ ศีรษะแยกเป็นการดัดแปลงดิจิทัลในช่วงมุมแคบ ขายังไม่แยกควบคุม รุ่นนี้มีเก้าแบบ เพิ่มบนเวทีได้ 12 ตัว และควบคุมพร้อมกันสูงสุดสองตัวด้วยสองมือ ไม่มีชุดเสียงพากย์อัตโนมัติ

## โครงสร้างสำหรับพัฒนาต่อ

```text
src/main.ts           การโต้ตอบ การปรับเทียบ และวงรอบแสดงภาพ
src/ui.ts             โครงหน้าสตูดิโอและกล่องตั้งค่า
src/core.ts           สัญญาณนิ้ว mapping ตัวควบคุม และการกรอง
src/ensemble.ts       จับคู่มือซ้าย/ขวากับตัวควบคุมอิสระ และใช้โปรไฟล์รายมือ
src/camera.ts         เปิด/ปิดกล้อง และรับส่งเฟรมกับ worker
src/vision-worker.ts  MediaPipe และการเลือก GPU/CPU
src/renderer.ts       ตัวหนังแยกชิ้น ฉาก และจุดมือ
src/characters.ts     ข้อมูล/รูปเวกเตอร์เก้าตัว ข้อต่อ ปาก และอุปกรณ์
src/theng-reference.ts รูปเท่งตามภาพผู้ใช้ สี ลายผ้า และรูปแขนแยกชิ้น
src/prayut-art.ts      รูปไอยุทธ์และข้อต่อจากแบบประยุทธ์
src/thaksin-art.ts     รูปแม้วจากภาพผู้ใช้และหมุดข้อต่อ
src/contemporary-art.ts แบบวิตรและหนู
src/leather-style.ts   ลายเถาใบฉลุและชุดหนังร่วมสำหรับสี่ตัวร่วมสมัย
src/performance.ts    ชุดท่าตัวอย่างสำหรับทดสอบงานตัวหนัง ไม่รวมในแอปจริง
src/style.css         หน้าสตูดิโอและการรองรับขนาดจอ
scripts/              เตรียมโมเดล/WASM และ bundle classic worker
tests/                หน้าทดสอบเบราว์เซอร์และภาพตัวอย่าง
public/vision/        โมเดล/WASM ที่ให้บริการจากเครื่อง
public/characters/    SVG ท่าพักที่สร้างจากข้อมูลเดียวกับ Canvas
```

เมื่อแก้ `vision-worker.ts` ให้เริ่ม dev server ใหม่เพื่อ bundle classic worker อีกครั้ง หรือรัน `node scripts/build-worker.mjs` แล้วเปิดกล้องใหม่

เมื่อแก้รูปใน `src/characters.ts` ให้รัน `npm run export:characters` เพื่อสร้าง SVG และภาพรวมใหม่ การ build และเปิด dev server จะทำขั้นตอนนี้ให้อัตโนมัติ SVG กับ Canvas ใช้โครงสร้างชิ้นส่วนและจุดหมุนชุดเดียวกัน การสลับตัวไม่เพิ่มแอนิเมชันอัตโนมัติทับมือจริง

โมเดลใช้ Hand Landmarker float16 version 1 จาก Google แพ็กเกจ MediaPipe ตรึงเวอร์ชันไว้ใน package.json และ dependencies ทั้งหมดบันทึกใน package-lock.json ดูต้นทางและ checksum ใน `public/vision/model-info.json`

เอกสารทางเทคนิค: [MediaPipe Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js), [สิทธิ์และ secure context ของ getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)
